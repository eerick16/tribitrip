# HU-015. Registrar reservas de clientes

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F06. **Prioridad y periodo planificados:** Alta, semana 4. **Estado:** Implementado.

- Como asesor de viajes.
- Necesito registrar una reserva a partir de una cotización aceptada.
- Para conservar la información de los servicios contratados por el cliente.

## Criterios de aceptación

- Una reserva puede generarse a partir de una cotización aceptada.
- Se conserva la información del cliente, servicios, fechas e importes.
- Cada reserva tiene un folio interno.
- Se puede consultar y actualizar su estado.
- La reserva aparece en el historial comercial del cliente.
- El registro es interno y no realiza reservas reales en sistemas externos.

## Comportamiento observado

Cotización aceptada y oportunidad ganada; copia persistente y alta idempotente.

**Requerimientos relacionados:** [RF-08](../requerimientos-funcionales/RF-08.md), [RF-12](../requerimientos-funcionales/RF-12.md), [RNF-04](../requerimientos-no-funcionales/RNF-04.md).
