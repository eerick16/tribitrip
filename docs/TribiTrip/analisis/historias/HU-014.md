# HU-014. Programar tareas de seguimiento

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F05. **Prioridad y periodo planificados:** Alta, semana 3–4. **Estado:** Fuera del alcance.

- Como asesor.
- Necesito programar tareas de seguimiento con fechas límite.
- Para recordar las actividades pendientes y evitar perder oportunidades de venta.

## Criterios de aceptación

- Se pueden crear tareas vinculadas a clientes u oportunidades.
- Cada tarea tiene descripción, responsable, fecha límite y estado.
- Se pueden marcar tareas como completadas.
- Se identifican las tareas pendientes y vencidas.
- Se pueden consultar las tareas asignadas al usuario.

## Comportamiento observado

Las tareas de seguimiento pertenecen a F05.

**Requerimientos relacionados:** [RF-07](../requerimientos-funcionales/RF-07.md).

**Suite relacionada:** Sin suite. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar la entidad de tareas de seguimiento.
- T02. Implementar endpoints de creación y actualización.
- T03. Crear formulario de programación de tareas.
- T04. Desarrollar el listado de tareas pendientes.
- T05. Implementar indicadores de tareas vencidas.
- T06. Integrar tareas con oportunidades y clientes.
- T07. Probar fechas límite, responsables y estados.

La numeración de tareas es local a esta historia.
