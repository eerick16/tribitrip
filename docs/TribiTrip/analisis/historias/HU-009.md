# HU-009. Consultar catálogo básico de servicios turísticos

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F04. **Prioridad y periodo planificados:** Media, semana 3. **Estado:** Implementado.

- Como asesor de viajes.
- Necesito consultar los paquetes y servicios turísticos disponibles.
- Para seleccionar las alternativas que mejor se adapten a las necesidades del cliente.

## Criterios de aceptación

- Se pueden consultar los servicios y paquetes registrados.
- Cada servicio muestra nombre, descripción, precio de referencia y proveedor cuando corresponda.
- Se pueden buscar servicios por nombre o destino.
- Los servicios pueden seleccionarse para incorporarlos a una cotización.

## Comportamiento observado

Consulta y selección de servicios o paquetes; precio y proveedor de referencia.

**Requerimientos relacionados:** [RF-13](../requerimientos-funcionales/RF-13.md).

**Suite relacionada:** quote.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar el modelo de datos del catálogo básico.
- T02. Configurar el esquema de servicios y paquetes con sus precios de referencia.
- T03. Implementar endpoints de consulta del catálogo.
- T04. Crear la interfaz de listado de servicios.
- T05. Implementar búsqueda y filtros por destino.
- T06. Integrar la selección de servicios con el cotizador.
- T07. Realizar pruebas de consulta y selección.

La numeración de tareas es local a esta historia.
