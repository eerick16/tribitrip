# HU-017. Consultar indicadores comerciales

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F07. **Prioridad y periodo planificados:** Media, semana 4. **Estado:** Implementado.

- Como administrador.
- Necesito visualizar indicadores de clientes, oportunidades, cotizaciones y ventas.
- Para evaluar el desempeño comercial de la agencia.

## Criterios de aceptación

- Se muestra la cantidad de clientes y prospectos registrados.
- Se muestran oportunidades abiertas, ganadas y perdidas.
- Se calcula una tasa básica de conversión.
- Se muestra el importe de las ventas registradas.
- Los indicadores corresponden a la información almacenada.

## Comportamiento observado

El panel muestra indicadores de clientes, oportunidades, conversión y ventas. Los indicadores de tareas pendientes y vencidas están fuera del MVP.

**Requerimientos relacionados:** [RF-10](../requerimientos-funcionales/RF-10.md).

**Suite relacionada:** commercial.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Definir los indicadores y sus fórmulas.
- T02. Implementar consultas agregadas en la base de datos.
- T03. Crear endpoints de indicadores.
- T04. Diseñar la interfaz del dashboard.
- T05. Implementar tarjetas y gráficas básicas.
- T06. Integrar el dashboard con la API.
- T07. Validar los cálculos utilizando datos de prueba.

La numeración de tareas es local a esta historia.
