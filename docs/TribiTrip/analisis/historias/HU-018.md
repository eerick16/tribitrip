# HU-018. Consultar reportes comerciales

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F07. **Prioridad y periodo planificados:** Media, semana 4. **Estado:** Implementado.

- Como administrador.
- Necesito consultar reportes de destinos solicitados y resultados comerciales.
- Para identificar tendencias y apoyar la toma de decisiones.

## Criterios de aceptación

- Se pueden consultar los destinos más solicitados.
- Se muestran las ventas registradas por periodo.
- Se pueden filtrar resultados por fechas.
- Los resultados se presentan mediante tablas o gráficas.
- La información coincide con los registros del CRM.

## Comportamiento observado

Destinos y ventas por fechas inclusivas de Ciudad de México.

**Requerimientos relacionados:** [RF-10](../requerimientos-funcionales/RF-10.md), [RNF-03](../requerimientos-no-funcionales/RNF-03.md).

**Suite relacionada:** commercial.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Definir los reportes y sus métricas.
- T02. Implementar consultas de destinos y ventas.
- T03. Crear endpoints de reportes.
- T04. Desarrollar componentes de tablas y gráficas.
- T05. Implementar filtros por periodo.
- T06. Integrar las consultas con el frontend.
- T07. Realizar pruebas de exactitud de resultados.

La numeración de tareas es local a esta historia.
