# HU-016. Registrar pagos informativos

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F06. **Prioridad y periodo planificados:** Media, semana 4. **Estado:** Implementado.

- Como asesor.
- Necesito registrar los pagos informados por los clientes.
- Para conocer cuánto han cubierto y cuál es el saldo pendiente de cada reserva.

## Criterios de aceptación

- Se pueden registrar fecha, monto, método informado y referencia.
- Cada pago se asocia a una reserva.
- Se calcula el total registrado y el saldo pendiente.
- Se puede consultar el historial de pagos.
- No se ejecutan cargos bancarios ni se procesan pagos electrónicos.

## Comportamiento observado

Movimientos informativos y saldo; la implementación permite excedentes y devolución de cambio.

**Requerimientos relacionados:** [RF-09](../requerimientos-funcionales/RF-09.md), [RF-12](../requerimientos-funcionales/RF-12.md), [RNF-04](../requerimientos-no-funcionales/RNF-04.md).

**Suite relacionada:** reservation.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar la entidad de pagos informativos.
- T02. Crear relaciones con las reservas.
- T03. Implementar endpoints de registro y consulta.
- T04. Implementar el cálculo de saldos.
- T05. Crear formulario de registro de pagos.
- T06. Desarrollar el historial de pagos por reserva.
- T07. Validar importes y referencias.
- T08. Realizar pruebas de cálculo y persistencia.

La numeración de tareas es local a esta historia.
