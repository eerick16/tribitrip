# HU-011. Administrar cotizaciones y sus estados

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F04. **Prioridad y periodo planificados:** Alta, semana 3–4. **Estado:** Implementado.

- Como asesor.
- Necesito consultar, modificar y actualizar el estado de las cotizaciones.
- Para conocer cuáles están pendientes, aceptadas o rechazadas.

## Criterios de aceptación

- Se pueden consultar las cotizaciones asociadas a una oportunidad.
- Se manejan estados de borrador, enviada, aceptada, rechazada y vencida.
- Se pueden crear versiones de una propuesta sin perder las anteriores.
- Los cambios de estado se guardan correctamente.
- Se puede identificar la cotización aceptada.

## Comportamiento observado

Versiones y transiciones; índice parcial de una aceptada por oportunidad.

**Requerimientos relacionados:** [RF-06](../requerimientos-funcionales/RF-06.md), [RF-12](../requerimientos-funcionales/RF-12.md), [RNF-04](../requerimientos-no-funcionales/RNF-04.md).

**Suite relacionada:** quote.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Definir reglas de transición entre estados.
- T02. Implementar endpoints de consulta y actualización.
- T03. Implementar versionado de cotizaciones.
- T04. Crear el listado de cotizaciones.
- T05. Desarrollar la vista de detalle.
- T06. Implementar controles para actualizar estados.
- T07. Validar restricciones de modificación.
- T08. Probar el historial y los cambios de estado.

La numeración de tareas es local a esta historia.
