# HU-006. Registrar solicitudes de viaje

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F03. **Prioridad y periodo planificados:** Alta, semana 3. **Estado:** Implementado.

- Como asesor.
- Necesito registrar destino, fechas, presupuesto y número de viajeros.
- Para identificar las necesidades de cada prospecto.

## Criterios de aceptación

La solicitud queda vinculada a un cliente, contiene los datos principales del viaje y puede consultarse y actualizarse.

## Comportamiento observado

Alta, consulta y edición; responsable derivado del contacto.

**Requerimientos relacionados:** [RF-04](../requerimientos-funcionales/RF-04.md), [RNF-04](../requerimientos-no-funcionales/RNF-04.md).

**Suite relacionada:** travel.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar el esquema de solicitudes embebidas en el cliente.
- T02. Implementar endpoints para crear, consultar y actualizar solicitudes.
- T03. Crear formulario de solicitud de viaje.
- T04. Implementar campos de destino, fechas, presupuesto y viajeros.
- T05. Asociar solicitudes a clientes y asesores.
- T06. Validar fechas, importes y campos obligatorios.
- T07. Probar el registro y la consulta de solicitudes.

La numeración de tareas es local a esta historia.
