# HU-001. Iniciar sesión en el sistema

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F01. **Prioridad y periodo planificados:** Alta, semana 2. **Estado:** Implementado.

- Como usuario autorizado.
- Necesito iniciar sesión mediante correo electrónico y contraseña.
- Para acceder de forma segura a las funcionalidades correspondientes a mi rol.

## Criterios de aceptación

El sistema valida las credenciales, permite el acceso a usuarios activos, rechaza credenciales incorrectas, protege las rutas privadas y permite cerrar sesión.

## Comportamiento observado

Acceso activo por correo; la cookie se restaura con `/api/auth/me`.

**Requerimientos relacionados:** [RF-01](../requerimientos-funcionales/RF-01.md), [RNF-01](../requerimientos-no-funcionales/RNF-01.md), [RNF-02](../requerimientos-no-funcionales/RNF-02.md).

**Suite relacionada:** app.test.js y security.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar el esquema de usuarios y los campos de autenticación.
- T02. Implementar el almacenamiento seguro de contraseñas.
- T03. Desarrollar el endpoint de inicio de sesión.
- T04. Implementar validación de sesiones y protección de rutas.
- T05. Crear la interfaz de inicio de sesión.
- T06. Integrar el formulario con la API.
- T07. Implementar cierre de sesión y manejo de errores.
- T08. Ejecutar pruebas de autenticación.

La numeración de tareas es local a esta historia.
