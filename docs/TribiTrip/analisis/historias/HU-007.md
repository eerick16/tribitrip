# HU-007. Gestionar oportunidades comerciales

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F03. **Prioridad y periodo planificados:** Alta, semana 3. **Estado:** Implementada.

- Como asesor.
- Necesito administrar oportunidades comerciales.
- Para dar seguimiento a los prospectos durante el proceso de venta.

## Criterios de aceptación

Se pueden crear oportunidades, asignar responsables, actualizar etapas y registrar resultados ganados o perdidos.

## Comportamiento observado

Al crear la oportunidad, el sistema asigna automáticamente como responsable al asesor del contacto asociado a la solicitud. Esta asignación satisface el criterio de asignar responsables.

**Requerimientos relacionados:** [RF-05](../requerimientos-funcionales/RF-05.md), [RF-12](../requerimientos-funcionales/RF-12.md).

**Suite relacionada:** opportunity.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar la entidad de oportunidades.
- T02. Definir las etapas del proceso comercial.
- T03. Implementar endpoints de oportunidades.
- T04. Desarrollar el formulario de creación y edición.
- T05. Implementar asignación de asesores.
- T06. Registrar cambios de estado y resultado comercial.
- T07. Realizar pruebas de transición entre etapas.

La numeración de tareas es local a esta historia.
