# HU-013. Registrar interacciones con clientes

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F05. **Prioridad y periodo planificados:** Alta, semana 3. **Estado:** Fuera del alcance.

- Como asesor de viajes.
- Necesito registrar llamadas, mensajes, reuniones y observaciones.
- Para mantener un historial de las comunicaciones con cada cliente.

## Criterios de aceptación

- Se pueden registrar interacciones asociadas a clientes u oportunidades.
- Cada interacción contiene tipo, fecha, descripción y responsable.
- El historial se muestra cronológicamente.
- Las interacciones permanecen disponibles para consulta posterior.

## Comportamiento observado

El registro de interacciones pertenece a F05.

**Requerimientos relacionados:** [RF-07](../requerimientos-funcionales/RF-07.md).

**Suite relacionada:** Sin suite. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar la entidad de interacciones comerciales.
- T02. Crear las relaciones con clientes y oportunidades.
- T03. Implementar endpoints de registro y consulta.
- T04. Desarrollar el formulario de nueva interacción.
- T05. Crear la vista de historial cronológico.
- T06. Integrar el historial en la ficha del cliente.
- T07. Ejecutar pruebas de registro y consulta.

La numeración de tareas es local a esta historia.
