# HU-012. Generar documento de cotización

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F04. **Prioridad y periodo planificados:** Media, semana 4. **Estado:** Implementado.

- Como asesor.
- Necesito generar una cotización en un formato imprimible.
- Para compartir una propuesta clara y profesional con el cliente.

## Criterios de aceptación

- El documento muestra los datos del cliente y de la agencia.
- Incluye servicios, cantidades, precios y total.
- Presenta vigencia, condiciones y folio.
- Puede imprimirse o exportarse a PDF.
- Los importes coinciden con los registrados en el sistema.

## Comportamiento observado

Documento HTML imprimible; el PDF se obtiene mediante el diálogo del navegador.

**Requerimientos relacionados:** [RF-06](../requerimientos-funcionales/RF-06.md).

**Suite relacionada:** quote.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Diseñar la plantilla del documento.
- T02. Implementar la obtención de datos de la cotización.
- T03. Desarrollar la generación del documento.
- T04. Incorporar datos del cliente, conceptos y condiciones.
- T05. Implementar la opción de impresión o PDF.
- T06. Validar formato y cálculos.
- T07. Realizar pruebas con cotizaciones de diferentes tamaños.

La numeración de tareas es local a esta historia.
