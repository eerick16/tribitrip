# HU-002. Administrar usuarios y roles

[Índice de historias](../historias.md) · [Matriz](../trazabilidad.md)

**Épica:** F01. **Prioridad y periodo planificados:** Alta, semana 2. **Estado:** Implementado.

- Como administrador.
- Necesito crear, consultar, editar y desactivar usuarios, asignándoles permisos de acuerdo con su rol,.
- Para controlar el acceso al CRM.

## Criterios de aceptación

El administrador gestiona usuarios, puede asignar roles y desactivar cuentas; los asesores no pueden realizar acciones administrativas.

## Comportamiento observado

Alta, edición, rol y desactivación; el backend revoca sesiones al editar.

**Requerimientos relacionados:** [RF-01](../requerimientos-funcionales/RF-01.md), [RNF-01](../requerimientos-no-funcionales/RNF-01.md), [RNF-02](../requerimientos-no-funcionales/RNF-02.md).

**Suite relacionada:** app.test.js y security.test.js. La aceptación manual queda pendiente.

## Actividades planificadas

- T01. Definir la matriz de permisos por rol.
- T02. Implementar el alta, la consulta, la edición y la desactivación de usuarios.
- T03. Desarrollar middleware de autorización por roles.
- T04. Crear la interfaz de administración de usuarios.
- T05. Implementar activación y desactivación de cuentas.
- T06. Validar permisos desde frontend y backend.
- T07. Realizar pruebas de autorización.

La numeración de tareas es local a esta historia.
