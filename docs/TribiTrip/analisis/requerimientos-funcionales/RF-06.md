# RF-06. Gestión de cotizaciones

[Índice](../requerimientos-funcionales.md) · [Matriz](../trazabilidad.md)

## Especificación

**Objetivo:** Preparar y conservar propuestas económicas.

**Actores:** Asesor y administrador.

*   Crear cotizaciones asociadas a oportunidades comerciales.
*   Generar un folio interno para cada cotización.
*   Registrar vigencia, servicios incluidos, cantidades, precios unitarios, impuestos y cargos.
*   Calcular subtotales y total general.
*   Registrar condiciones comerciales y observaciones.
*   Permitir diferentes versiones de una cotización.
*   Administrar estados: Borrador, Enviada, Aceptada, Rechazada y Vencida.
*   Generar un documento HTML por versión, imprimible o guardable como PDF desde el navegador.

## Evaluación frente a la implementación

**Estado:** Implementado.

Seleccionar oportunidad visible, agregar conceptos, guardar folio y actualizar versión o estado. Los importes se recalculan en centavos; una sola cotización aceptada por oportunidad. La versión aceptada queda protegida. La vista HTML permite imprimir o guardar PDF desde el navegador.

**Precondiciones:** Oportunidad visible y conceptos válidos; para aceptar, cumplir las transiciones y la vigencia.

**Postcondiciones:** Se conserva folio, versión, importes y estado. Las versiones históricas siguen disponibles.

**Alternativas y validaciones:** Si ya existe otra aceptada en la oportunidad o la revisión cambió, se rechaza la escritura. El PDF requiere el diálogo de impresión.
