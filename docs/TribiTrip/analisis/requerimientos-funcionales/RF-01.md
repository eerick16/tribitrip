# RF-01. Autenticación y gestión de usuarios

[Índice](../requerimientos-funcionales.md) · [Matriz](../trazabilidad.md)

## Especificación

**Objetivo:** Controlar el acceso al CRM y gestionar cuentas.

**Actores:** Usuario activo, administrador y asesor.

*   El sistema deberá permitir iniciar y cerrar sesión mediante correo electrónico y contraseña.
*   Deberá manejar dos roles: Administrador y Asesor de viajes.
*   El administrador podrá gestionar usuarios y consultar toda la información.
*   Los asesores podrán administrar los registros correspondientes según sus permisos.
*   El sistema deberá restringir el acceso a funcionalidades según el rol.

## Evaluación frente a la implementación

**Estado:** Parcialmente implementado.

Abrir sesión con correo y contraseña de una cuenta activa; consultar o administrar cuentas según rol; cerrar sesión y retirar cookie. La edición revoca sesiones y protege contra autodesactivación o degradación propia.

**Precondiciones:** Cuenta activa y correo válido para iniciar; sesión vigente para salir.

**Postcondiciones:** El cliente restaura sesión al recargar y limpia el estado al salir.

**Alternativas y validaciones:** Credenciales incorrectas o cuenta inactiva devuelven 401. Un asesor que intenta administrar cuentas recibe 403.
