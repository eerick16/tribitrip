# RF-05. Gestión de oportunidades comerciales

[Índice](../requerimientos-funcionales.md) · [Matriz](../trazabilidad.md)

## Especificación

**Objetivo:** Organizar el seguimiento de oportunidades en el embudo.

**Actores:** Asesor y administrador.

*   Crear oportunidades de venta relacionadas con solicitudes de viaje.
*   Asignar automáticamente como responsable de la oportunidad al asesor del contacto asociado a la solicitud.
*   Administrar las etapas: Solicitud recibida, Cotización, Seguimiento, Negociación, Ganada y Perdida.
*   Actualizar el estado de las oportunidades.
*   El historial de interacciones y tareas está fuera del MVP.
*   Visualizar el avance mediante un pipeline comercial.

## Evaluación frente a la implementación

**Estado:** Implementado.

Al crear una oportunidad desde una solicitud visible, el sistema asigna automáticamente al asesor del contacto asociado. El usuario puede actualizar la etapa y registrar el resultado comercial. El administrador puede consultar y filtrar el embudo. La validación de revisión evita escrituras obsoletas.

**Precondiciones:** Solicitud visible y título válido. Para el embudo, rol administrador.

**Postcondiciones:** La oportunidad queda vinculada a solicitud, cliente y asesor; el cierre queda registrado.

**Alternativas y validaciones:** Revisión obsoleta produce un conflicto. El asesor no puede acceder al embudo administrativo.
