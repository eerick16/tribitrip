# RF-13. Catálogo básico de proveedores

[Índice](../requerimientos-funcionales.md) · [Matriz](../trazabilidad.md)

## Especificación

**Objetivo:** Conservar referencias a proveedores de servicios.

**Actores:** Asesor y administrador.

*   Registrar como texto el proveedor de referencia de un servicio turístico.
*   Conservar el proveedor de referencia en conceptos de catálogo y permitir un proveedor manual en reservas.
*   El mantenimiento independiente de proveedores queda pendiente.

## Evaluación frente a la implementación

**Estado:** Parcialmente implementado.

Consultar o registrar un servicio o paquete y guardar proveedor como texto de referencia. La cotización copia el dato del catálogo y la reserva permite proveedor manual. No existe colección ni administración independiente de proveedores.

**Precondiciones:** Sesión activa y campos obligatorios válidos para dar de alta un servicio o paquete.

**Postcondiciones:** El servicio queda disponible en el catálogo y puede seleccionarse para una cotización.

**Alternativas y validaciones:** Un concepto manual permite cotizar sin entrada de catálogo. No hay mantenimiento independiente del proveedor.
