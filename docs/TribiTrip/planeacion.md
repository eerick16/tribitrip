# Planeación

[Portada](../TribiTrip.md) · [Cronograma](planeacion/cronograma.md) · [Historias y tareas](analisis/historias.md) · [Matriz](analisis/trazabilidad.md)

El cronograma distribuye el MVP en cinco semanas con Scrum y Kanban. Azure Boards gestiona el trabajo del proyecto y está conectado a GitHub. Martin Muñoz lidera el proyecto y es responsable de la justificación. Gustavo tiene a cargo el alcance, los requerimientos y las limitaciones. El equipo comparte la definición de tareas. Eduardo Rodríguez elaboró las minutas. [Minutas](minutas.md)

La fase de análisis contempla requisitos, diseño y preparación. Las fases de construcción cubren acceso y contactos, flujo comercial e indicadores. La etapa de cierre contempla integración, pruebas, documentación y liberación. Las fichas HU incluyen el desglose de tareas y la matriz identifica los RF/RNF vinculados. El código acredita módulos y las suites acreditan casos escritos. Las fechas del calendario son planificadas. Testing está integrado y validado. La aceptación manual y la liberación definitiva de Staging siguen pendientes. [Evidencias](evidencias.md)
